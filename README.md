# 2025-2026 Güz / BSM311 - Web Programlama / Proje Ödevi

## Proje Hakkında Kısa Açıklama
Proje Spor Salonu Yönetim ve Randevu Sistemi olarak geliştirilmiştir. Sistem, spor salonlarının sunduğu hizmetleri, antrenörlerin uzmanlık alanlarını, üyelerin randevularını ve yapay zekâ tabanlı egzersiz önerilerini yönetebilecek niteliktedir.

## Projenin Teknik Detayları

ASP.NET Core MVC (.NET 8), Entity Framework Core ve SQL Server kullanarak salon, hizmet, antrenör ve üye süreçlerini kapsayan uçtan uca CRUD ve randevu yönetim platformu geliştirildi.

REST API ve LINQ sorguları ile tarih/müsaitlik bazlı dinamik antrenör ve randevu filtreleme servisleri tasarlandı.

Rol Bazlı Yetkilendirme (Admin/Üye), çakışan randevu kontrolü, onay mekanizması ile istemci ve sunucu taraflı veri doğrulama (Data Validation) süreçleri uygulandı.

Yapay zeka API entegrasyonu ile kullanıcı ölçülerine göre kişiselleştirilmiş egzersiz ve diyet önerisi sunan modül eklendi.

## Projede Kullanılan Teknolojiler
- Arkayüz için ASP.NET Core MVC, .NET 8, C#
- Önyüz için HTML5, CSS3, Bootstrap 5, JavaScript, jQuery
- Veritabanı için SQL Server
